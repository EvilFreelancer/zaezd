# Экосистема вокруг Tutu MCP, что ещё можно подключить

Всё, что помечено как проверенное, реально дёргалось из консоли 19 августа 2026 года.

## MCP Apps, интерактивный интерфейс прямо в диалоге

Это самая важная часть документа для трека интерфейсных решений.

В январе 2026 года в MCP приняли расширение MCP Apps (SEP-1865), спецификация датирована 2026-01-26. Её написали совместно Anthropic, OpenAI и мейнтейнеры сообщественного проекта MCP-UI. Суть в том, что инструмент возвращает не только текст для модели, но и указатель на интерактивный HTML для человека, а хост рендерит его в песочном iframe рядом с диалогом.

Контракт короткий и его стоит знать наизусть, потому что Туту его не реализует, а значит ниша свободна.

Инструмент объявляет свой шаблон через `_meta`.

```json
{
  "name": "search_rail",
  "_meta": {
    "ui": {
      "resourceUri": "ui://tutu-ui/rail-results",
      "visibility": ["model", "app"]
    }
  }
}
```

Ресурс отдаётся с особым MIME-типом, в MVP поддержан только он.

```json
{
  "uri": "ui://tutu-ui/rail-results",
  "mimeType": "text/html;profile=mcp-app",
  "text": "<!DOCTYPE html>...",
  "_meta": {
    "ui": {
      "csp": {
        "connectDomains": ["https://mcp.tutu.ru"],
        "resourceDomains": ["https://cdn1.tu-tu.ru", "https://cdn2.tu-tu.ru"]
      },
      "prefersBorder": true
    }
  }
}
```

Внутри iframe работает полноценный JSON-RPC поверх `postMessage`. Доступные вызовы от виджета к хосту.

| Метод | Назначение |
|---|---|
| `ui/initialize` | рукопожатие, хост возвращает тему и размеры контейнера |
| `tools/call` | виджет сам зовёт инструмент, например перезапускает поиск с другим фильтром |
| `resources/read` | чтение ресурса |
| `ui/open-link` | открыть внешний URL, ровно то, что нужно для чекаута Туту |
| `ui/message` | отправить сообщение в чат от имени виджета |
| `ui/request-display-mode` | попросить полноэкранный режим |
| `ui/update-model-context` | сообщить модели, что выбрал пользователь |

Уведомления от хоста к виджету включают `ui/notifications/tool-input`, `tool-result`, `tool-cancelled`, `size-changed`, `host-context-changed` и `ui/resource-teardown`.

По умолчанию CSP максимально жёсткий, `default-src 'none'`, никаких внешних соединений. Домены надо объявлять явно. Для веб-хостов требуется двойной iframe, внешний того же происхождения проверяет сообщения, внутренний изолированный грузит HTML.

Практический вывод. Прокси-сервер поверх Tutu MCP, который добавляет `ui://` ресурсы, получает интерактивную карту отелей, схему вагона с кликабельными местами и сравнение рейсов прямо в Claude, ChatGPT или VS Code, без единой строчки собственного фронтенд-хостинга. `ui/open-link` при этом ведёт на настоящий чекаут Туту, то есть юридическая модель Туту не нарушается.

Ссылки. [Спецификация MCP Apps](https://github.com/modelcontextprotocol/ext-apps/blob/main/specification/2026-01-26/apps.mdx), [анонс в блоге MCP](https://blog.modelcontextprotocol.io/posts/2025-11-21-mcp-apps/), [проект MCP-UI](https://mcpui.dev/).

## Открытые API, проверенные на живых запросах

Эти семь работают без ключа и без регистрации. Колонка со временем - реальный замер.

| Сервис | Что даёт | Ключ | Проверка |
|---|---|---|---|
| [KudaGo](https://docs.kudago.com/api/) | афиша событий и мест | не нужен | 200, 1,1 с, 3718 событий по Казани |
| [Open-Meteo](https://open-meteo.com/) | погода на 16 дней вперёд и архив с 1940 года | не нужен | 200, 1,4 с |
| [isDayOff](https://www.isdayoff.ru/) | производственный календарь России | не нужен | 200, 2,1 с, строка `000011000001100000110000011000` за сентябрь 2026 |
| [Nominatim](https://nominatim.openstreetmap.org/) | геокодинг OSM | не нужен | 200, 1,5 с |
| [Wikivoyage RU](https://ru.wikivoyage.org/w/api.php) | путеводители по городам | не нужен | 200, 6,1 КБ по Казани |
| [OSRM](https://router.project-osrm.org/) | маршрутизация и время в пути | не нужен | 200, 1,2 с |
| Overpass API | произвольные POI из OSM | не нужен | публичные зеркала |

Про KudaGo важная оговорка. Локаций всего шесть, из них пять городов - Москва, Санкт-Петербург, Казань, Екатеринбург, Нижний Новгород, плюс раздел "Интересные материалы". Для демо на этих городах данных с избытком, для всей России покрытия нет.

Форма события и места удобная. У места есть `coords {lat, lon}`, `address`, `categories[]` вроде `amusement`, `bar`, `sights`, `recreation`, и HTML-описание. Это склеивается с координатами отелей Туту напрямую, без геокодинга.

Календарь isDayOff отдаёт строку по символу на день, ноль рабочий, единица выходной. Сентябрь 2026 читается сразу, и на этом строится подбор длинных выходных.

## Российские картографические и транспортные API

| Сервис | Что даёт | Условия |
|---|---|---|
| [Яндекс Геокодер](https://yandex.ru/maps-api/tariffs) | адрес в координаты и обратно | до 25 000 запросов в сутки бесплатно при отображении на Яндекс.Картах |
| [Яндекс Расписания](https://yandex.ru/dev/rasp/) | расписания самолётов, поездов, электричек, автобусов, судов, ближайшие станции к точке | бесплатный API по ключу |
| [2ГИС](https://dev.2gis.com/ru/api) | самые точные городские данные по России, POI, карты | бесплатный тестовый ключ |
| [MapLibre](https://maplibre.org/) плюс OSM-тайлы | карта без вендора и без ключа | открытая лицензия |

Яндекс Расписания заслуживают отдельного внимания как дополнение к Туту. Там есть то, чего в Tutu MCP нет по признанию самого сервера, а именно станционный уровень для наземного транспорта и запрос ближайших станций к произвольной точке. Связка получается естественная, Туту продаёт билет, Яндекс отвечает на вопрос "а с какого вокзала и как до него добраться".

## Языковые модели, доступные из России

| Платформа | Особенности |
|---|---|
| GigaChat от Сбера | function calling на старших тарифах, оплата в рублях, данные в России, в марте 2026 вышел GigaChat Enterprise |
| YandexGPT через Yandex Cloud | ассистенты и агенты, эмбеддинги, векторные базы, дообучение |
| Локальные модели | vLLM или llama.cpp на своём железе, полный контроль контекста |
| Роутеры | зарубежный OpenRouter, российский KodikRouter от Arkhitekh AI |

Для хакатона выбор модели влияет на одну вещь сильнее прочего - на длину контекста. Манифест Tutu MCP занимает около 25,5 тысяч токенов, и на модели с окном в 32K места на диалог почти не остаётся. Туту сам писал, что проверял сервер на Qwen3-30B именно ради этого. Если проект целится в локальную модель, урезание манифеста становится не украшением, а условием работоспособности.

## Готовые MCP-серверы, которые складываются с Туту

Поиск по реестру коннекторов не дал ни одного тревел-сервера, но общие подходят.

- Файловая система и память для сохранения профиля путешественника между сессиями;
- Playwright или Puppeteer для сценариев, где надо дожать то, чего нет в API;
- PostgreSQL для истории поисков и аналитики;
- Exa или Firecrawl для веб-контекста, но с оговоркой. Правила Туту прямо запрещают подменять отсутствующее поле ответа веб-поиском, так что внешний поиск можно использовать только для вещей, которых в Туту нет в принципе, и с явной пометкой источника;
- Sequential thinking для длинных цепочек планирования маршрута.

## Как это складывается

Смысл подключать что-то ещё есть ровно там, где у Туту дыра, и таких дыр четыре.

1. Туту знает, как доехать, но не знает, зачем ехать. Это закрывает KudaGo, Wikivoyage и Overpass;
2. Туту знает даты, но не знает, какая будет погода и не выпадет ли поездка на рабочий день. Это закрывают Open-Meteo и isDayOff;
3. Туту знает город, но для наземного транспорта не знает вокзал и не умеет считать "как добраться до вокзала". Это закрывают Яндекс Расписания, 2ГИС и OSRM;
4. Туту отдаёт координаты отелей, но не отдаёт карту. Это закрывает любой картографический движок, и дешевле всего MapLibre без ключа.

Каждая из четырёх дыр - готовое обоснование для проекта. Не "мы прикрутили погоду, потому что можем", а "поиск Туту не отвечает на вопрос, который путешественник задаёт первым".
