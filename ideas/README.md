## Готовые файлы UI

В папке [ui-kit](ui-kit/) лежит выжатая дизайн-система Туту.

- `kite-tokens.json` - 1726 семантических токенов Kite 5.10.0, разрешённых до конечных значений, отдельно для светлой и тёмной темы;
- `tutu-core.css` - компактная палитра `--tutu-*` для быстрой вёрстки;
- `theme-switcher.js` - оригинальный переключатель тем Туту.

## Сырые данные

В папке [raw](raw/) лежат исходники, на которых построены все выводы.

- `tools-list.json` - полный ответ `tools/list`, 107 КБ;
- `sample-*.json` - реальные ответы поисков по маршруту Москва - Казань на 5 сентября 2026;
- `sample-seatmap.json` - схема мест поезда 206Х, 86 КБ, восемь вагонов;
- `sample-checkout.json` - собранные ссылки на оплату для поезда и отеля;
- `resource-*.json` - содержимое ресурсов `tutu://`;
- `hackathon-deck.pdf` - презентация открытия хакатона;
- `mcp.sh` и `tool.sh` - шелл-хелперы, которыми снималась вся документация.

Повторить любой замер можно так.

```bash
./ideas/raw/tool.sh search_rail '{"origin":"Москва","destination":"Казань","departure_date":"2026-09-05","page_size":2}'
```

## Главные выводы в трёх абзацах

Сервер Туту сделан аккуратно. Read-only по юридическим причинам, прогрессивное раскрытие документации через отдельные инструменты-плейбуки, честные предупреждения о том, чего в ответе нет, метка `source=mcp` в ссылках для атрибуции. Пять продуктов, шестнадцать инструментов, шесть ресурсов, один промпт.

Дыр в нём четыре, и каждая годится как обоснование проекта. Манифест инструментов весит около 25,5 тысяч токенов, из них 21 841 символ приходится на один `create_checkout_link`. Ни один инструмент не объявляет `outputSchema`, весь JSON приезжает строкой. Ресурсов `ui://` нет вообще, то есть спецификация MCP Apps от января 2026 года остаётся незанятой нишей. Наземный транспорт не принимает вокзал на входе, хотя в ответе название вокзала есть.

Самый недоиспользованный источник данных на сервере - схема мест в поезде. Восемьдесят шесть килобайт на запрос, полная геометрия мест, посчитанное расстояние до туалета, женские купе, разрешение на животных. В текстовом чате это нечитаемо в принципе, а именно поезд и автобус с подтверждённым выбором мест дают единственный на всём сервере путь до корзины, которая работает в холодном браузере.
